# Provenance and Licence Ledger Rules

Every externally sourced or generated production input must be traceable.

For each third-party code module, asset pack, model, animation, audio file, texture, dataset, or generated asset used in an experiment or promoted component, record at minimum:

- stable name/ID;
- source URL or repository;
- source version/commit when available;
- author/publisher;
- licence or terms;
- commercial-use status;
- attribution obligations;
- modifications made by By JTT;
- experiment(s) using it;
- validation status;
- redistribution status.

Generated assets additionally require the generator/model/service name and date plus any source images/assets that materially influenced the generation.

Do not treat "free" as a licence. Do not publish or redistribute an asset merely because it can be used in a game. Where licence status is ambiguous, keep the asset out of public builds until resolved.

Promoted reusable components should prefer MIT, Apache-2.0, BSD, CC0, or similarly compatible terms when technically competitive, but licence alone does not override product quality or security.
