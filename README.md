# AI Game Development Pipeline — By JTT

An evidence-driven, open-source AI game development lab and production pipeline for discovering faster, higher-quality ways to prototype, build, test, ship, and iterate games.

This repository is the canonical research and factory workspace behind the **By JTT AI Game Development Lab**. It benchmarks competing engines, runtimes, AI agents, asset pipelines, physics systems, QA methods, deployment routes, and other production choices using reproducible experiments rather than opinion.

## Core principle

**Reuse the best solved system before writing custom code.** Every meaningful technical decision is treated as a competition between engine-native capability, proven open source, commercial tooling, AI generation, and bespoke implementation. Custom code is used only when it is the strongest lifecycle choice.

## What this repository will contain

- reproducible AI game-development benchmarks;
- competing prototype implementations;
- experiment specifications and evidence;
- reusable production components promoted from successful experiments;
- asset, licence, provenance, and technology registries;
- deterministic playtest and visual-QA infrastructure;
- published research inputs for `games.byjtt.com`;
- candidate games that may graduate into dedicated production repositories.

## First benchmark

`BYJTT-LAB-001` will implement the same mobile-first 3D action/collection slice across multiple serious runtimes, initially including Three.js/WebGPU, PlayCanvas, Babylon.js, Godot, Unity, and Defold where technically appropriate.

The benchmark will measure AI-production efficiency, gameplay and presentation quality, engineering quality, performance, mobile suitability, build/deployment reliability, and economics.
