# Workflow scorecard

This scorecard is a living evidence index, not a self-rating exercise. A category may reach 10 only when the linked evidence demonstrates it under real concurrent game-development work.

| Category | Current evidence state | Promotion evidence |
|---|---|---|
| Durable source of truth | strong architecture, limited real-run proof | fresh sessions resume from GitHub alone across multiple workstreams |
| Collision prevention | real stale-write collision observed; GitHub protected data | near-zero unplanned overlap before edits across Benchmark 001 lanes |
| Environment routing | contract exists | runtime claims consistently produced in execution-capable environments |
| Evidence integrity | strong | every behaviour claim maps to fresh verifier-specific evidence |
| Human attention efficiency | designed | routine coordination rarely needs human intervention |
| Parallel throughput | unproven | measured validated elapsed-time improvement after integration |
| Handoff/resumability | designed | fresh agent resumes with negligible rediscovery |
| Recovery | partially executable | failed QA/retry/alternative routing demonstrated in real work |
| Integration safety | weakness exposed | short-lived branches + merge-order verification reduce rework |
| Context efficiency | designed | measured context volume per completed work unit falls without quality loss |
| Simplicity | improving | coordination overhead remains smaller than prevented conflict/rework |
| Control-plane fidelity | prototype only | UI projects live GitHub/workstream/evidence state and writes decisions through |
| Orchestration build-vs-buy | research stage | real workflow benchmark demonstrates whether extra substrate earns complexity |
| Long-term maintainability | architecture only | conventions survive new sessions/models/tools and repository growth |

## Rule

Do not average these into a vanity number. The weakest material category constrains the overall workflow. The target is a system that keeps producing good evidence when multiple independent agents, tools and game runtimes are active—not a document that says 10/10.
